# SyncVeil (Android Version)

SyncVeil is a privacy-first platform offering encrypted data vaults, secure identity management, and real-time breach monitoring.

## Android Application

This repository has been rewritten as a native Android application using:
- Kotlin
- Jetpack Compose
- Room Database (Local encrypted vault simulation)

### Features
- **Dashboard**: Quick access to all platform features.
- **Encrypted Vault**: Locally store your secure notes using Room Database.
- **Modern UI**: Built with Material Design 3 and Edge-to-Edge support.

### Build Instructions
Run `./gradlew assembleDebug` to build the app, or run tests using Android Studio.
